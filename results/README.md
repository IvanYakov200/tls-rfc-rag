# Сохранённые эксперименты

Файлы `dev-A.jsonl`, `dev-B.jsonl` и `dev-C.jsonl` первоначально получены на пяти пробных вопросах. В этом пилоте модель сама воспроизводила английскую цитату. Файлы пилота можно отличить по полю `quote` в `raw_output` и отсутствию `code_digest`.

В зафиксированной версии кода модель выбирает номер выдержки, после чего программа извлекает текст из RFC. Новый прогон dev заменяет соответствующие файлы. В новых трассах сохраняется `code_digest`. Прогоны по 20 финальным вопросам записываются в отдельные файлы `test-*.jsonl` после завершения эксперимента. Каждый успешный вызов модели также кешируется по ключу, включающему версию кода, digest модели, вопрос и найденный контекст. При прерывании достаточно повторить команду.

Счётчик `answered` включает ответы, прошедшие техническую проверку цитаты. Для оценки фактической правильности и полноты необходима отдельная содержательная проверка.
