Содержание оценивается по всем обязательным частям вопроса. Строгий зачёт дополнительно требует поддержки каждого утверждения его собственными цитатами. Faithfulness считается по утверждениям. Recall усредняется по отвечаемым вопросам и требует покрытия размеченных байтовых интервалов. Корректный отказ засчитывается в обе оценки ответа.

Автоматически проверены байтовые координаты и текст 282 ссылок.

В основном результате недоказанными признаны 5 из 118 утверждений (4,2%).

## Разбор расхождений

В test-15 отбор 40 → 5 потерял размеченный интервал RFC 7919, сохранив оба интервала RFC 10015. Это единственный актуальный вопрос с неполным покрытием эталона в пятёрке.

Строгий балл потерян в пяти актуальных вопросах: dev-02, test-16, challenge-01, blind-01 и blind-07. В каждом оценщик отметил одно утверждение с недостаточной опорой на собственные цитаты. В test-16 и blind-07 он зачёл содержание ответа. На 58 отвечаемых вопросах полностью правильны по смыслу 55, строго подтверждены 53. Первый независимый прогон blind дал 19/20 строго, повтор на тех же вопросах — 18/20. Один вопрос в этом наборе меняет итог на пять процентных пунктов.

## Воспроизведение

Из корня проекта пересчитать сохранённый результат без сети:

```sh
PYTHONPATH=src python3 -m tls_rag.all_questions score
```

Для нового прогона укажите отдельную папку. Команды run и judge продолжают прерванный прогон с сохранённых записей.

```sh
PYTHONPATH=src .venv/bin/python -m tls_rag.all_questions run --out results/all_direct_new
PYTHONPATH=src .venv/bin/python -m tls_rag.all_questions judge --out results/all_direct_new
PYTHONPATH=src .venv/bin/python -m tls_rag.all_questions score --out results/all_direct_new
```
